# Родословная Солиных

Семейный сайт: древо снизу вверх с масштабом, страница каждого предка с источниками и фотографиями.

- `index.html` — вся страница: разметка, стили и скрипт. Дизайн правится здесь.
- `data.js` — данные о людях, собираются из рабочего древа исследования. Руками не править: перезапишется.
- `photos/web/` — фотографии и документы из семейного архива.

Открыть локально: просто открыть `index.html` в браузере (двойной клик) — сервер не нужен.
